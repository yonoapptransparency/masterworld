## 2024-05-15 - Icon-only Buttons Require Explicit Focus States\n**Learning:** When using icon-only buttons (like Trash2) in the admin dashboard, removing outline with `focus:outline-none` removes accessibility for keyboard users unless an explicit `focus-visible:ring` is added. Also, they must always have an `aria-label` and `title`.\n**Action:** Add `aria-label={...}`, `title={...}`, and `focus-visible:ring-2` (or similar) to any icon-only button to ensure full screen reader and keyboard navigation support.
