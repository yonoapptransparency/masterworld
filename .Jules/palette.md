## 2024-08-18 - Missing ARIA Labels on Icon-Only Buttons
**Learning:** I discovered a recurring accessibility pattern across the Admin dashboard tabs (`AdminCategoriesTab`, `AdminQuickLinksTab`, `AdminWebsiteFaqsTab`, `AdminDevelopersTab`, `AdminBannersTab`) where delete/remove actions used icon-only buttons containing just a Lucide `Trash2` icon. These buttons were missing `aria-label` attributes, rendering them inaccessible to screen reader users who wouldn't understand the purpose of the button.
**Action:** When adding new interactive elements, especially icon-only buttons in lists or forms, always explicitly ensure an `aria-label` attribute is added describing the button's action (e.g., "Remove item"). I should look for this pattern during code reviews or when adding new admin UI features.
