## 2025-03-01 - Accessible Icon-Only Buttons in Admin Panels
**Learning:** Icon-only buttons used in dynamically generated lists (like categories or tags) must have descriptive `aria-label`s and `title` attributes (e.g., `aria-label="Remove category Finance"`) for screen readers, as well as explicit `focus-visible` styling (like `focus-visible:ring-2 focus-visible:ring-rose-500 focus-visible:ring-offset-1 rounded-sm`) to clearly indicate keyboard focus. This ensures that admin operations remain fully accessible to all users without relying solely on visual cues or hover states.
**Action:** When adding or auditing icon-only action buttons (e.g., remove, edit, close) within iterative or list-based admin components, verify that both screen reader and keyboard focus requirements are explicitly implemented using Tailwind's `focus-visible:` utilities.
